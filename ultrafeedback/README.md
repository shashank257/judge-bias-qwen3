Put everything for this part **inside this folder**. Suggested layout:
```
ultrafeedback/
├── README.md          # what this part does, how to run it, key results
├── requirements.txt   # Python packages for this part
├── src/ or scripts/   # code
├── notebooks/         # notebooks (with outputs)
├── data/              # small inputs only (< 50 MB per file); large/raw data -> document how to download
└── results/           # tables, figures, logs that the report uses
```
